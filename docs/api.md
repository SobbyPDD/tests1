# Функции

## rectangle.py

### area(a, b)
**Описание**:

     Возвращает площадь прямоугольника со сторонами a и b.
            Параметры:
                    a (float): первая сторона прямоугольника, выраженная вещественным числом
                    b (float): вторая сторона прямоугольника, выраженная вещественным числом
            
            Возвращаемое значение:
                    S (float): площадь прямоугольника со сторонами a и b
**Пример вызова**:

    from rectangle import *
    a, b = map(int, input().split())
    print(area(a, b))

## triangle.py

### area(a, h)
**Описание**:

    Возвращает площадь треугольника со стороной a и с высотой h.
    
            Параметры:
                    a (float): первая сторона треугольника, выраженная вещественным числом
                    h (float): высота треугольника, выраженная вещественным числом
            
            Возвращаемое значение:
                    S (float): площадь треугольника со стороной a и с высотой h

**Пример вызова**:

    from triangle import *
    a, h = map(int, input().split())
    print(area(a, h))

### perimeter(a, b, c)
**Описание**:

    Возвращает периметр треугольника со сторонами a, b и c.
    
            Параметры:
                    a (float): первая сторона треугольника, выраженная вещественным числом
                    b (float): вторая сторона треугольника, выраженная вещественным числом
                    c (float): третья сторона треугольника, выраженная вещественным числом
            
            Возвращаемое значение:
                    P (float): периметр треугольника со сторонами a, b и c


**Пример вызова**:

    from triangle import *
    a, b, c = map(int, input().split())
    print(perimeter(a, b, c))
